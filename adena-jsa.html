Setup & Offline Use

Install to iPad Home Screen:

  1. Save this HTML file to your device (AirDrop, email, or Files app)
  2. Open the file in Safari on the iPad
  3. Tap the Share button, then "Add to Home Screen"
  4. The app now opens full-screen and works with no internet connection
  5. All data auto-saves to this device only, and resets to a blank JSA each new day
  6. To update the app, AirDrop a new version of the file and repeat step 4

Printing to PDF: Tap Print / PDF, then use Safari's Share → Print → pinch to zoom on the preview → Save as PDF.

On iPad: Tap the Share button in Safari → Print → Pinch to zoom on preview → Save as PDF
